# telegram-markup-bot

**Telegram-бот для рендеринга Markdown в формат, совместимый с Telegram (HTML).**

---

## Описание проекта

`telegram-markup-bot` — Telegram-бот на Python, который принимает Markdown (текст или файл), парсит его в внутреннее AST и рендерит в HTML, отображаемый в сообщениях Telegram.

---

## Основные возможности

- Парсинг Markdown (через `markdown-it-py`) с поддержкой списков, таблиц, блоков кода, цитат, спойлеров и прочих стандартных конструкций.
- Преобразование в внутренний AST и рендер в Telegram-совместимый HTML (`bot/core/parser.py`, `bot/core/transformer.py`, `bot/core/renderer.py`).
- Обработка Telegram MessageEntity (UTF-16 offsets) (`bot/core/entity_converter.py`).
- Автоматическое разбиение длинных сообщений по ограничению Telegram (≤ 4096 символов) (`bot/core/splitter.py`).
- Поддержка загрузки `.md`/`.txt` файлов (до 2 MB).

---

## Принцип работы и архитектура

1. Пользователь отправляет обычное сообщение с Markdown, прикрепляет файл (`.md`/`.txt`) или использует inline-режим с URL.
2. Входной текст получает обработчик в `bot/main.py`:
  - при document — бот скачивает файл (макс ~2 MB);
  - при inline-query с URL — бот пытается получить внешний ресурс (`fetch_external_content`).
3. Текст передаётся в `MarkdownParser` (`bot/core/parser.py`), который разбирает Markdown в токены (markdown-it-py).
4. `ASTTransformer` (`bot/core/transformer.py`) строит внутренний AST (узлы из `bot/core/ast_nodes.py`).
5. `TelegramRenderer` (`bot/core/renderer.py`) превращает AST в HTML, совместимый с Telegram (теги `<b>`, `<i>`, `<pre>`, `<code>`, `<blockquote>`, `<tg-spoiler>`, ссылки и т.д.).
6. `MessageSplitter` (`bot/core/splitter.py`) делит длинный HTML на безопасные фрагменты ≤4096 символов, стараясь не ломать теги.
7. Бот отправляет полученные фрагменты пользователю как одно или несколько сообщений.

## Быстрый старт

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Рекомендуется создать виртуальное окружение и активировать его:

```bash
python -m venv .venv
source .venv/bin/activate  # macOS / Linux
```

1. Установите зависимости для бота:

```bash
pip install -r bot/requirements.txt
```

1. Экспортируйте токен Telegram-бота:

```bash
export BOT_TOKEN="123:ABC..."
```

1. Запустите бота:

```bash
python bot/main.py
```

## Ограничения

- Максимальный размер загружаемого файла ~2 MB (ограничение, заложенное в обработке файлов).
- Telegram накладывает ограничение на длину сообщения ~4096 символов — бот автоматически разбивает слишком длинные рендеры.
